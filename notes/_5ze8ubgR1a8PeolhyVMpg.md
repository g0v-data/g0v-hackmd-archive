# 公民科技專案與社群資料庫

:::info
跳坑請至 g0v Slack 頻道 #g0v-database-專案清單-基礎建設清單
:::

【專案與社群資料庫：建立公民科技專案與社群資料庫】

已彙整超過 200 個程式開源授權之公民科技專案、超過 300 個公民科學及群眾外包計畫、超過 150 個各領域數位學習社群 (例如技術類型_QGIS 地理資料技術社群、地區類型_高雄軟體開發者社群、議題類型_TaiwanHR臺灣人資社群)。

預計彙整上述資料集，提供查詢服務網站，建立標籤架構，整合聯合國永續發展目標、數位解方對策種類 (例如群眾外包、大數據分析、開源硬體等)、108 課綱及素養對照表、政府政策範疇種類等，提供使用者自主查詢相關專案及社群，或進行系統推薦。資料庫成果將銜接國際 Civictech Guide 與 Democracylab，既有的國際型專案資料庫架構，促進國內外專案資訊流通。

### 採用哪些數位技術方案
* 對接國際專案標籤架構
    * Civictech Guide: The Tech 
        * 子分類 Participatory democracy 
        * 子分類 Govtech 
        * 子分類 Civic data 
        * 子分類 Advocacy tech 
        * 子分類 Media 
        * 子分類 Emerging tech 
    * Democracylab: Technologies Used 專案選擇的技術方案或框架
        * 子分類 CMS
        * 子分類 CRM
        * 子分類 Database
        * 子分類 Design
        * 子分類 Platform
* 數位解決方案
    * 對接國際專案標籤架構 Civictech Guide: Categories > The Tech 
    * 目前的項目大約有 40 個，用字有點口語化XD
        * 項目清單：https://docs.google.com/spreadsheets/d/1P1sCLPAQP9hUwMFVGzneg9lAIFLoYe_arsmgdUy23FA/edit
        * 例如：
            * 切豆腐掃描檔案 OCR
            * 挖掘紙本文獻接續數位化建檔
            * 針對非結構化報告文書內容結構化的填報工具
            * NFT / Hypercerts
            * 政府顧好資料供給，民間開發各種應用
            * 人才媒合
            * 物資媒合
            * 心理測驗問答引導
