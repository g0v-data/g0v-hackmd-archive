# 【方案評估】這場活動，該選用什麼樣的供餐型態呢？

## 便當 vs 外燴

| 評估項目 | 便當 | 外燴 |
| -------- | -------- | -------- |
| 人均取用 | 一人一個保底  | 晚來就沒了  |
| 取用時間  | 領取容易 | 要排隊 |
| 衛生風險 | 自己吃的時候才打開 | 飛沫風險  |
| 如何吃 | 便當比較難拿在手上吃 | 外燴可以拿在手上少少的吃，吃完再拿 |
| 菜色 | 很有可能會出現不喜歡吃的菜色 | 自己選自己想吃的菜色；便當難以入菜的菜色，例如麻油雞麵線 |
| 飲品 | 附湯 (不確定) | 可以選購甜湯、熱湯等 |
| 餐具 | 有環保鐵盒便當且廠商可以來回收 | 好像沒聽過有包辦環保餐盒的服務 |

## 下午茶茶點供餐型態
| 評估項目 | 餐盒 | 多樣化自取 |
| -------- | -------- | -------- |
| 人均取用 | 一人一份餐盒保底  | 晚來就沒了  |
| 取用時間  | 領取容易 | 要排隊 |
| 衛生風險 | 自己吃的時候才打開 | 飛沫風險  |
| 菜色 | 很有可能會出現不喜歡吃的品項 | 自己選自己想吃的餐點；餐點種類比較多元 |
| 垃圾 | 餐盒外盒垃圾很多 | 相對比較少 |


## 菜單品項種類，必須注意以下原則
- 必須有「素食」
- 必須設想「不吃牛肉者」，可以吃的餐點菜色
- 必須設想「不吃豬肉者」，可以吃的餐點菜色
- 提供「無麩質飲食」的餐點菜色
- 飲料
    - 必須有「無咖啡因的飲料」
    - 理想上，有冷，有熱

## 場地限制與清潔
- 需注意場地能否使用「明火、酒精燈」加熱保溫
    - 使用酒精燈需確認如何滅火（有的外燴不會提供滅火工具）
- 生日蛋糕
    - 如果場地有冰箱的話可以先買放到冰箱
    - 否則就要想一下當天如何取貨送到場地
- 飲料
    - 飲料茶桶的開關，正下方要有小桶子接著，避免飲料滴到場地地面
- 炸雞還蠻容易掉屑屑
