## 14:40-15:40 鏈結資料文獻臺灣譯本發表會
:::info
專案主頁面 👉 [透過 Wikibase 建立屬於圖書館的鏈結資料 Passage 專案的成果 臺灣譯本](https://hackmd.io/@wikidata-tw/oclc2019report) 🔗
:::

* 活動簡介：
    * 臺灣維基數據社群在 2025 年發起新一輪的鏈結資料(Linked Data)文獻翻譯專案，希望為臺灣社群建置更多相關的華語文獻，作為領域發展的基礎。
    * 本次翻譯選定由 OCLC 出版的【Creating Library Linked Data with Wikibase: Lessons Learned from Project Passage】作為翻譯目標，該文為 OCLC 與數間圖書館合作推動的實驗性計畫【Passage 專案】的結案報告。
    * 【Passage 專案】以 Wikibase 平台為實驗平台，旨在協助圖書館員們獲得第一手的鏈結資料經驗。並且透過這樣的實驗來對圖書館的 "資源-描述" 工作在新舊工作流程之中的異同與潛在挑戰。
    * 在專案期間，OCLC 與來自 16 間圖書館的圖書館員們發現了許多值得進一步討論與探索的議題，其中許多顯示了鏈結資料相較於現有系統有著顯著的效益，但是另一方面也有許多新的挑戰伴隨其中。
    * 本次活動將由社群譯者洪哲賢與 Wikidata Taiwan 共同召集人王文岳共同分享該報告中幾個結論，提出未來可能的社群工作模式與展望，本次活動歡迎所有關心文化與文化工作者共同瞭解 Wikidata/Wikibase 的鏈結資料工作模式如何協助現在的文化工作。
* 發表流程：
    * 30 mins 鏈結資料概念與 OCLC Wikibase  Passage 專案簡介
    * 30 mins 譯本翻譯的成果與經驗分享
* 發表者：Wikidata Taiwan 社群合作譯者洪哲賢、Wikidata Taiwan 社群共同召集人 王文岳
* 補充資料：
    * 什麼是鏈結資料(Linked Data)？
> 鏈結資料的目的是讓資料集能發布到全球網上，讓個別資料集和其它資料集的項目可相互連結，並避免資料筒倉效應（Data Silo Effect，或說資料穀倉效應）。
--摘自【以語意網技術整合網站異質資料供鏈結資料發布】

>鏈結資料必須符合四個規則：
    * 利用 URI (統一識別碼) 為事物/檔案命名
    * 以 HTTP 做為客戶端和伺服器端之間查詢及傳送 URI 的機制，使人或電腦可以查詢特定 URI 所代表事物的相關資訊
    * 伺服器端使用 RDF 與 SPARQL 等標準，提供更多的資訊。當伺服器端接獲客戶端對於特定 URI 的請求時，伺服器端會以標準格式將該 URI 所代表事物的相關資訊傳 回給客戶端。若客戶端是「人」，則伺服器端可回傳 HTML 格式的文件；若客戶端是「應用程式」，則伺服器端可回傳 RDF 格式的文件，以方便客戶端的應用程式再利用這些資訊
    * 對於特定URI所代表事物的相關資訊中，應包含與其他相關事物的連結(連結到該事物的URI)，使得事物間得以串連，以達成構築全域資料空間的目標
-- 整理自【鏈結資料在圖書館的應用】

>在開放資料五顆星中，五顆星開放資料即為鏈結開放資料(Linked Open Data)。
