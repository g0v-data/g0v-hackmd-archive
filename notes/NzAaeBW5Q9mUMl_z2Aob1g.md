## 第1部分
**第1/2段內容重點摘要**

1. **介面與視覺升級**  
   - 全站 UI 重新設計（亮色系、白底、柔和腳頁），稱為「豆腐」視覺風格。  
   - 首頁新增「最新議題」區塊；議題卡改用 icon 替代圖片，並以大圖突顯。  
   - 連結到新版 Civic Talk、MetaPolis、行事曆、Substack 電子報等外部資源，提供 API 按鈕取代爬蟲。

2. **前後端架構與資安**  
   - 現行前後端分離存在資安漏洞，計畫在年底前完成前後端合一（部署於 `next.vtaiwan.tw`）並正式取代主站。  
   - 加入 IP 限流與未來可能的 Cloudflare 4‑02 付費牆，以防止惡意大量請求與 token 費用濫用。

3. **Polis 與 SenseMaker 整合測試**  
   - 探討新版 Polis 是否能直接在 SenseMaker 上使用，分析流程包括議題分類與綜合判斷。  
   - 目前測試樣本較少（6 票），預計人數增多後能產出更精細的報告。

4. **AI 事實查核 MVP**  
   - 建立 `check.vtaiwan.tw` 服務，結合三個模型：  
     a. **Safeguard (GPT‑OSS)**：依社群守則過濾不當內容（色情、仇恨等）。  
     b. **相關性模型**：從 Cofacts API 取得候選文獻，篩選出最相關的 5 篇（門檻 0.65）。  
     c. **Gemma**：綜整結果，輸出可信度分數、信心指數與判斷（支持／反對／無法判定）。  
   - API 允許 GET/POST 呼叫；目前每日上限 300 次，超量會被封鎖。

5. **討論會議（即將舉辦）規劃**  
   - **議程與流程**：  
     1️⃣ 前 45 分鐘回顧上次討論與數據；  
     2️⃣ 45 分鐘分組討論（議題分享 → 深入討論 → 結果彙整）；  
     3️⃣ 40 分鐘全體分享與開放討論。  
   - **線上/線下協調**：  
     - 線上參與者可能較多，擔心分組過大，考慮採「大組」模式並使用 Google Doc 文字協同。  
     - 桌長（Thompson、Bestian）負責線上即時管理；Murmi 或 Mentimeter 供意見收集。  
     - 為避免噪音，線上麥克風預設關閉，僅透過文字或投票互動。

6. **參與者與角色分配**  
   - 實體參與者：Billy、Ellen、為然、其他待確認。  
   - 線上管理者：Thompson、Bestian（文件、桌長）、Josh（帳號與訊息出口）。  
   - 另有新加入成員 Soth（實體），需確認是否開麥與後勤（攝影/紀錄）角色。

7. **外部合作與資金**  
   - 與 GEMIC、Jigsaw（SenseMaker 開發者）正在接洽，計畫於 11 月實地調查台灣公民科技社群。  
   - 已與 OCF 確定合作，爭取 70‑80 萬新台幣；同時同步爭取 FNF 基金支持。  

8. **未來研究與產出方向**  
   - 3 大工作項目（10 個月）：  
     1️⃣ 文獻整理（AI + 數位工具在審議中的應用）。  
     2️⃣ 深度訪談（審議工作者與工具開發者）。  
     3️⃣ 跨界工作坊（審議者 ↔ 工具開發者的對話）。  
   - 從「審議流程設計→中期討論→結束後可信度」三個階段探討數位工具的角色與風險。

以上即為本段文字的主要資訊與行動要點。
