歡迎參與 vTaiwan！

我們目前正在開發與測試 **Civic Talk**，希望建立一個讓大家可以共同蒐集資料、整理不同觀點，並逐步形成公共議題討論基礎的平台。

主網站：
https://civic.vtaiwan.tw/

開源專案：
https://github.com/g0v/civic-talk-hono

如果你剛加入 vTaiwan，其實不需要先了解程式或審議民主的所有工具，很適合直接從「使用者」的角度開始試玩 Civic Talk。

你可以試著走過以下流程：

1. **瀏覽目前已有的公共議題**
   看看議題說明、參考素材、不同參與者提出的意見，以及後續的彙整內容。

2. **使用 Google 或 GitHub 登入**
   登入後，就可以進一步參與內容投稿。

3. **建立一個你關心的議題**
   想想看：「如果希望大家一起理解、討論這件事，議題應該怎麼描述？」

4. **投稿參考素材**
   可以加入新聞、研究、政府資料、倡議文章或其他相關資訊，讓不同觀點都有資料可以參照。

5. **提出自己的意見**
   不一定要有完整答案，也可以提出疑問、補充觀點，或指出目前討論中被忽略的面向。

6. **對其他人的意見進行投票**
   Civic Talk 希望不只是累積留言，而是協助參與者逐漸看見：大家在哪些地方有共識？哪些地方仍有分歧？目前有對其他人的意見進行投票，累積一定的意見和票數後，未來會再開發意見綜整的功能。

目前 Civic Talk **仍在持續測試與改進中**，所以我們也很需要第一次使用者的眼睛。

如果你遇到介面看不懂、不知道下一步該做什麼、某個流程不順，甚至只是覺得「這裡怪怪的」，都很有價值。

不需要先想出解法，只要告訴我們：

**「我原本以為這裡會怎麼運作，但實際上不是。」**

這種回饋往往就是改善平台最好用的資訊。


測試時也請留意：投稿內容會保留作者資訊，也會實際更新網站上正在討論的議題。

如果純粹是測試介面與功能，可以進到名為「[這是測試](https://civic.vtaiwan.tw/issues/8)」的測試用議題中。


Civic Talk 還在成長中。與其把它當成一個已經完成的產品，更歡迎把它看成一個大家可以一起試、一起討論、一起修改的公共數位空間。

歡迎來玩新平台、參與討論，也歡迎挑毛病、提點子。🙂

### 第一步：你是公民還是志願者？

#### 公民
閱讀議題說明、參與討論，分享你對公共議題的觀點。
優先查看：已有說明、可參與討論的議題。

#### 志願者
協助蒐集素材，並用自己的 AI 整理資訊，建立公共討論的共同基礎。
優先查看：待蒐集素材或待彙整的議題。

### 第二步：

#### 公民：

1. 找到有興趣的議題
2. 瀏覽既有的意見，進行投票
3. 發表自己的想法(可體驗"AI幫幫忙"流程)


#### 志願者：
1. 找到素材收集中、彙整中的議題
2. 幫忙找素材、貢獻到Civic talk平台
3. 幫忙彙整(可體驗AI彙整prompt的流程)
