# 大松 + 鼓勵獎金

討論頻道 #jothon-bonusthon

## 基本構想：將鼓勵獎金，納入大松標配

優點：
- 各專案可以爭取獎金，來支付機器費用

課題：
- 錢從哪裡來？
    - 贊助者若需要捐款證明，要留意捐款者贊助的費用，會有手續費、行政處理費，所以實際能夠當作獎金的數字會小幅下修，這部分要向捐助者說明
    - 贊助者若是提供現金且不需要捐款證明，也是需要主辦單位來處理，看如何記帳至獎金額度
- 額度與組數
- 如何決定金額
    - 平方投票法 網頁工具：一個輕量級的平方投票活動網頁應用程式。使用 Nuxt.js、Prisma 和 Tailwind CSS 建構。
        - https://qv.seangau.xyz/
        - https://github.com/g0v/quadratic-voting-lite
    - 平方投票法 RxC 基金會的網頁工具 https://quadraticvote.radicalxchange.org
- 如何支付獎金
    - 匯款，因為通常分配後的資金數字有零頭
    - 要不要簽領據？
        - 揪松團會請獲獎團隊推派一位代表來簽領據，這樣 OCF 才能夠出款匯款

## 「評審決選」方式

零時小學校-專案孵化計畫
- 評審們的排序結果，採用「孔多塞投票法 Condorcet voting」，計算結果會有同順位，再進行討論 (搭配當期獎金額度)
