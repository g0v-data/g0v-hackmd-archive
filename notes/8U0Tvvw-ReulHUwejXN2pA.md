## 活動介紹

8/18 週二上午 10:30-12:00 內水流域規劃方法建構的工作坊，活動重點：

1. 輔助各單位掌握各個堤內內水集水範圍認識與細分，並找出主幹線/主河道，了解城市裡的「分水區位/分水嶺」

2. 介紹常見公民資料行動數位工具，包含河溪網河川守護地圖可以記錄主河道主幹線環境現況，災害歷史地圖可收錄重要的災害老照片，iNaturalist 生物調查，也建議建立該流域範圍的歷史素材地圖；也想蒐集還有什麼樣的資料主題地圖，對於該流域來說也很重要呢？如水質通報地圖、戶外舒適度地圖、乾式滯洪及常態水體水域位置地圖、潛在水源資源指認地圖 (原水管線、水廠尾水、再生水、郊山逕流) 等

3. 潛力營造行動指認：勾選人水互動類型 (歷史上、當代現況、期待營造)，勾選 淨水功能 / 貯水功能 / 環境融入水元素 / 主水路營造，並指認出位置與用地屬性

## 工作方法建構

### 集水範圍歸屬

- 如何歸屬範圍：最大範圍，各範圍
    - 資料
        - 台北市排水系統-中區-線上地圖 https://goo.gl/maps/SPxHhQoSR1ahYf4TA
        - 台北市排水-北區、南區 https://maps.app.goo.gl/QqQx3swFJEcBXCZx9
        - 地下管線 
            - https://dig.taipei/Tpdig/Public/pipe3.html
            - 3D https://3dgis.reac.taipei/sgwptools/reac/Apps/pipe.html
    - 台北市內水排水分區類型說明
        - 山坡地佔該範圍的比例
            - 第一類 玉成抽水站、新生建國抽水站、雙園抽水站、...等等
                - 分水嶺山系屬於郊山
            - 第二類 外雙溪、磺港溪、磺溪、水磨坑溪、內溝溪...等沿線兩側
                - 分水嶺山系海拔較高
        - 從屬哪一個大河系統
            - 基隆河系統
                - 縣市上下游分段
            - 新店溪系統 https://g0v.hackmd.io/@chewei/xindian-river-watershed/
                - 縣市左右範圍
            - 淡水河系統
                - 但因河面較寬，相對來說較無兩側人本生活圈建構的潛力
    - 範圍內再細分，找出「分水嶺軸帶 / 起點區位」
        - TODO 
            - 這部分可能要產出一些圖說界定步驟
            - 指認範圍+抽水站
            - 把水路線條的流動方向標記好箭頭
            - 找出範圍內，比較明確的支流型態的集水範圍子分區
            - 對於「網狀水網」地區，指認「分水區位」
        - 基於排水管線配置現況
            - 玉成抽水站範圍
            - 雙園抽水站範圍，本身屬於河階地區
                - 例如植物園到和平三元路口，成為「分水區位」
                    - 和平西路北側的寧波西街會先流入重慶南路，再流至和平三元街口，流入三元街主要箱涵
                    - 而和平西路南側的寧波西街，則匯入三元街寧波西街路口
                - 例如艋舺大道成為分水嶺
                - 例如果菜批發市場、青年公園等均是「起點區位」
            - 臺北市立大學、中正紀念堂園區，國父紀念館，博愛國小興雅國中，都是「起點區位」
            - 南港路三段本身成為分水嶺，北側與南側不同子系統
            - 大安森林公園人造土丘，成為分水區位
            - 中崙一帶回顧探討
                - 地形改變：1910年代日本人進行填土工程改善艋舺淹水問題，主要的取土地就是中崙。據報告紀錄，取土面積約36甲，取走近400萬立方米的土石。
                    - https://www.facebook.com/groups/582154450196478/posts/1523061162772464
                - 目前的分水嶺，與延吉街遺址位置類似，距今 3200-1800 年-延吉街遺址-圓山文化，延吉街30巷15-1號華南花園別墅所在的突起小丘。
                    - 地址描述文字來源：https://hub.arcgis.com/datasets/IDT::%E9%81%BA%E5%9D%80/explore?location=25.046351%2C121.545594%2C16.85
                    - https://archaeogis.ihp.sinica.edu.tw/map/#/gis
                    - http://webgis.sinica.edu.tw/website/twnarchaesites/viewer.htm
    - 找出主河道
        - 主河道樣態
            - 類型：主幹線路線，使用地區大型道路
            - 類型：主幹線沿著堤防內側的道路走向
        - 主河道健康度，工具可使用河溪守護網 https://iriver.tw/
            - Case: 柳川 https://iriver.tw/zh-hant/node/188
            - Case: 中港大排、瓦磘溝
        - 命題：什麼樣的三面光？
            - 這個主河道的歷史探究，自然溪流經人為工程，或完全為人為工程
                - 例如新生南北路於 1933 年規劃始建，1942 南段完工，規劃興建，1972 南段箱涵化，1983 高架橋完工也完成北段溝渠建設
                - 例如瑠公圳公園-頂好廣場-龍門廣場-安和路-文昌街280巷，農業時期水體遺線，混凝土化則於 ? 年份，於 ? 年依據建國北路區分東側西側成為不同系統
                - 歷年物種推論
            - 與都市系統的相互關係，例如平面車道、高架橋、地下捷運、高壓電纜 (新生北路南京至渭水路口)
            - 沿線加蓋比例
            - 基於基流量設計子母溝
            - 內側仿生化
            - 磺港溪新奇岩段
            - 街區人為互動，如清溪川、中港大排
            - 主河道沿線能否有水域設置潛力點，例如永春埤濕地公園、南港新新公園、大湖公園
                - 「串」字形象
                - 玉成抽水站集水範圍：臥龍公園，景勤二號公園，三興國小，五常公園，永吉國中、玉東公園
    - 「襲奪」案例
        - 民族實中段的瑠公圳，原本是由西南往東北輸水，目前這段雨水下水道反而是往西流入新店溪
        - 大灣遺線的箱涵，到了建國北路之後，就往北轉入建國北路的箱涵
        - 林森南路開南商工往北銜接天津街的水路，目前已分為南北兩側，各屬於不同的排水分區
- 整理出水環境改造場域樣態
    - 1. 最上游的「分水區位/分水嶺」位置，評估水環境營造方案
        - 類型一：公園處指認的依山地區與山區，豹山山區與永春陂、民族實中
        - 類型二：台北市立大學校區校園街廓、青年公園、中正紀念堂園區、臺大
    - 2. 垂直向度，建物屋頂，猶如巨木樹梢樹冠；此類區位，結合綠建築、雨水中水運用
    - 3. 主河道軸帶
        - 中下游區位，可評估匯入貯流調節功能，例如大安森林公園、敦北大排的區位
        - 留意是否也被指定為淹水避難場所
    - 4. 抽水站區位
    - 留意 公共工程、交通工程、建築修行為 等翻新改建契機，以及軟體類活動 (路跑夜跑、遶境 ..等，參考人水互動種類輔助發想探討)
        - 臺北市市區排水審查相關文件 https://service.taipei/case-detail/CK005
        - 捷運復舊
        - 水路沿線建物街區https://wenshanoasis.wixsite.com/mysite
    - 水源：
        - 再生水
        - 原水資源，管線位置
        - 自來水水廠尾水
- 臺北盆地人水互動的用途行為種類列舉
    - 參考：賓果表格內容
    - 水井：台北城水井、南萬華楊氏古厝水井、建國啤酒廠深井、防災用水預備點
    - 建物雨水回收與利用
    - 常態水體營造濕地
    - 划船，醉月湖
    - 帶狀邊界：北科大、臺大新生南路側、民族實中、公務人力中心北側
