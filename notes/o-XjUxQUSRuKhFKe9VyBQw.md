# 2026／03 g0v 大松命名

:::success
g0v 黑客松（aka 大松）活動名稱大部分是參與者在活動前提案投票後命名的，讓你可以冠名 g0v 黑客松！

本次大松：g0v 第柒拾貳次新源意碼大造化黑客松 New Source x Mindful Code Hackath72n
活動時間：3/29 週日
活動地點：臺南市好想工作室
報名網址：https://g0v-jothon.kktix.cc/events/g0v-hackath72n

:::
