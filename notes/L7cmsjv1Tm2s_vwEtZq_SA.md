### ❓ What is PipZ for Mac?

🪟 PipZ is a macOS utility for creating multiple floating Picture-in-Picture browser windows that stay visible while you work in other applications.

### ❓ Does PipZ only work with videos?

📚 No. PipZ can be used for videos, documentation, dashboards, presentations, charts, web panels, and other browser content.

♾️ Yes. PipZ is specifically designed as a multi-PiP application and supports multiple floating windows simultaneously.

### ❓ Can I make a PiP transparent?

🎚️ Yes. Each PiP window can have its own opacity setting, with configurable quick opacity presets.

### ❓ What is click-through mode?

🖱️ Click-through allows mouse clicks and scrolling to pass through a PiP to the application underneath while keeping the PiP visible.

### ❓ Can PipZ automatically refresh a webpage?

🔄 Yes. Supported intervals include 5 seconds, 10 seconds, 30 seconds, 1 minute, 5 minutes, and 15 minutes, along with an Off option.

### ❓ Does PipZ support Chrome and Safari?

🌐 Yes. PipZ supports Chrome and Safari along with several other browsers, including Firefox, Edge, Brave, Arc, Vivaldi, Opera, Naver Whale, and Comet.
