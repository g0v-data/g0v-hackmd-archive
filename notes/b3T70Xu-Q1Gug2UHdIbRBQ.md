# 5-5 台日韓青年參與公民科技社群現況｜g0v 公民科技專案與社群手冊｜g0v Civic Tech Project & Community Handbook
### Chapter 5: 數位公民素養內涵與各國實踐經驗
## 5-5 台日韓青年參與公民科技社群現況

:::info
本節資訊來自零時小學校觀察以及「2023 面海松（Facing the Ocean Meet & Hack，FtO）」的 U22 受訪者，包含 2 位韓國大學生、2 位日本大學生、2 位台灣大學生、1 位台灣國中生。

#### 面海松（Facing the Ocean Meet & Hack，FtO）

Facing the Ocean「面向海洋」（FtO）是由生活在西太平洋的公民黑客組成的社群，包含台灣、日本、韓國與香港等地區。「面海松」（Facing the Ocean Meet & Hack）是由 FtO 社群自 2019 年以來籌辦的黑客松系列活動。

「2023 面海松」由 g0v international、Code for Korea、Code for Japan 三個單位協作舉辦。

:::

### 一、韓國

#### 1. U22 的公民科技參與現況

韓國大學生受訪者分享，在韓國，公民科技在 U22 的族群中知名度不高，其中以 Code for Korea 較為人知。此外也有受訪者提到 NullFull (널채움)、Semicolon 學生社群（詳細介紹請參考 4-1）。

然而雖然公民科技社群知名度不高，但 U22 專案數量卻日益提升。例如面對 2023 年韓國隨機殺人事件頻起，四位大學生組成 01ab 團隊自發性建置無恐怖（테러리스，terrorless）平台，彙整相關資訊，以公民身份共同建構社會安全網。

而韓國學生在公民科技領域時常遇到資源有限、缺乏經驗以及平衡學業承諾等挑戰。

#### 2. 參與公民科技的管道與建議

其中一位資工背景的大學生表示，學校的人普遍不知道 Code for Korea 的存在，可能是因為對 U22 宣傳不足，而年輕人通常是透過新聞或朋友介紹獲得資訊。

此外，一般來說，學生並沒有足夠資源執行專案，因此為了獲得資源，韓國學生通常是透過參與各種競賽發展專案。然而競賽過程中涉及評審的個人意見，因此，儘管某些專案非常重要，卻經常被忽視。此外，在受訪學生經驗中，韓國目前沒有明確針對公民科技的資源，學生多數運用技術資源發展專案，例如 goorm 公司提供開發者支持系統、Semicolon 學生社群提供協作平台。

而若希望更近一步培養學生公民科技思維與能力，教育單位可以引入與公民科技相關的課程或研討會，讓學生接觸到公民科技並提供實際技能教學。同時也可以建立導師計畫，邀請經驗豐富的公民科技參與者指導有熱忱的青年，進而彌補熱情與實際執行間的差距，為學生提供了更清晰的參與路徑。此外，充分利用學生經常使用的平台，如 Discord，為公民科技討論、黑客松或創意發起的專門頻道。最後，也可以透過提供學分認證、實習機會，甚至獎學金等認可與獎勵方式，鼓勵學生積極參與公民科技。


### 二、日本

#### 1. U22 的公民科技參與現況

在日本青年族群中，有兩個影響力較大的大型技術社群， Code for Japan 與 Supporters（為青年提供程式開發相關的教育機會），兩者皆希望透過技術創造民主。而目前 U22 青年參與公民科技的積極度提升，尤其以高中生與大學生為最多。特別是東京 COVID-19 網站的開發，有許多高中和大學生積極參與開源軟件開發。東京 COVID-19 網站為日本 47 個縣建立地區版本的開源參考，其中許多由學生帶領進行。

而學生參與公民科技的原因，一部分是因為做公民科技專案可以豐富學習歷程與履歷，提升進入市場時的個人價值，而不願參與部分原因為沒有動力。此外，青年參與公民科技社群的經驗因人而異，有些學生可能在加入公民科技社群時感到困惑，因為在公民科技專案中，一切自由的同時也帶來責任。

#### 2. 參與公民科技的管道與建議

在日本，大多數青年透過 Twitter、Instagram 和網站搜尋找到公民科技社群。此外，他們也從前輩、朋友和學生社群中獲得對此些組織的評價。此外，日本受訪學生表示，以 Code for Japan 為例，CfJ 針對 22 歲以下學生舉辦「U22 公民科技挑戰賽（Civictech Challenge Cup U-22）」，參賽者利用線上環境開發 demo 並展示作品，此比賽可作為學生首次參與公民科技的入口，並提供資源來支持他們的公民科技專案。

然而受訪學生仍認為對學生來說，公民科技專案的資源仍有限。而若要加強青年的參與，其中一位受訪者認為，對青年來說重要的是能透過發展公民科技專案，應用其他領域的技能，因此應該要增加相關的論述與經驗分享。

此外受訪者也認為，若部分行業、社群、公司等單位能高度認可公民科技專案的經驗，學生會更容易去接觸公民科技專案，雖然這是外在動機，但當學生實際參與專案，便可意識到公民科技所帶來的價值，進而轉為內在動機。例如，讓更多單位在招聘時，能參考面試者過往在公民科技的參與開源的貢獻。此外，學生在向公司或大學介紹他們的過往經歷時，學生應該努力強調將他們在公民科技參與中的主動性、領導能力和創新的能力等素質，以獲得適當的認可。當公民科技經驗得到認可和重視，學生可以在參與公民科技倡議時考慮未來的職業前景。

### 三、台灣

#### 1. U22 的公民科技參與現況

在台灣 U22 青年參與公民科技社群或專案的人數不多，但近幾年有所提升。在台灣教育體制中，多數學生忙於升學考試，因此 18 歲以下較少人參與。然而，2019 年起，108 新課綱鼓勵學生自主學習，並安排特定自主學習課程讓學生設計與完成自主學習計畫，因此對科技感興趣的學生開始有機會接觸公民科技社群，甚至參與或發起公民科技專案。

在受訪學生的觀察與經驗中，能讓 U22 青年參與的公民科技社群或專案的場合和其他年齡層無異，即為 g0v 零時政府社群。而目前台灣在公民科技社群的發展上，有著希望能將參與者年齡下降的目標，讓公民黑客的數位素養與議題洞悉能力得以向下扎根。例如 g0v 零時政府松團於 2019 發起零時小學校專案，培養中學生與大學生自發性協作數位專案，解決生活及社會問題。

至於由 22 歲以下的人發起的專案，依據受訪學生的觀察，學生想解決的問題通常和自己本身有關，因此大多數專案的目標都和教育有非常緊密的連結。例如，「參考書推薦平台」幫助學生找到最適合他們的參考書或備考書籍；「Course API」收集台灣開放課程 API 整合在一個平台上。

而就一位大學生受訪者的經驗而言，認為缺乏維護專案的時間對於學生發起的專案來說是一個大問題，國高中生有升學壓力，大學生則會有社團、營隊活動等外務和不亞於國高中的課業壓力，時間總是不夠用。此外，受訪學生也提出目前遇到的最大問題為行銷宣傳，雖然有嘗試過但效果有限，只要宣傳一停止，就沒有人在網站上留下新評論。

#### 2. 參與公民科技的管道與建議

三位受訪者在參與公民科技社群的經驗中，皆提到 g0v 揪松團發起的「零時小學校 Sch001」教育專案，此專案透過將公民科技議題與協作模式帶入教育現場，透過與學校合作課程、開發各式線上開放課程、舉辦營隊、專案孵化競賽等方式，提高學生的數位公民素養，並拓展公民科技社群的參與年齡層與多元化，受訪者之一認為此專案有效提供學生參與公民科技專案和社群的管道。以其中一位大一學生為例，自己在高中時參加的第一個 g0v 活動是零時小學校舉辦的「夏日線上源力增能營」，活動消息是由學校物理老師提供，也因為此活動認識 g0v，並開始關注社群的消息。

此外也有受訪者提及，目前能鼓勵學生參與公民科技社群及專案的現有資源為 Notion for Education、GitHub Student Developer Pack、AWS Educate 等，皆以開發資源為主。

而如何再提升 U22 青年參與度，受訪者認為以現在的資源來說，除了 g0v 揪松團與零時小學校自行舉辦的各種形式的課程以外，SITCON（學生計算機年會）也時常舉辦 Hour of Code (HoC) 或推廣 OSCVPass 的各式活動，讓年輕一輩能透過實際的工作坊做一點專案的簡單工作，進而接觸並實際貢獻開源專案，而其中的專案有一大部分是公民科技專案，受訪者本身有不少朋友皆是藉此第一次接觸到公民科技專案。

然而，就受訪者觀察，通常大部分這種工作坊的受眾非常廣泛，但通常是年紀較小的國小、國高中生。這些學生的自備技能也非常廣泛，並不只限縮於資訊能力。他們通常對類似的工作坊表示很喜歡，但卻鮮少在後續的公民科技社群出現，或是持續參與公民科技專案。建議要有較能夠讓初學者能自己主動參與並必備技術較低的專案，讓轉換率增加。

此外，如果要讓更多青少年能有更多機會接觸或參加公民科技，最有可能接觸到的還是集中在以教育方面為題的專案或社群，例如開放課程整合的專案。雖然受訪者並不認為只有教育主題是學生可以入手的類型，但在「動機」上相對其他類型來說應該最有感觸且最有行動力。而此些學生現在大多出現在分散的 Discord 群組，各自討論不同類型的題目，而絕大多數均為讀書會、共學社群，或是單純玩樂的社團性質。建議可思考如何將他們的行動力轉變成幫助更多同學，且運用科技成形的專案，並預估可能需要的資源。

而針對大學生的參與度，如果公民科技社群中有某些缺人手的專案，可以考慮和大學端合作開設服務學習課程，藉此媒合需要服務時數的學生以及需要人手的專案，不但大學生有機會接觸公民科技，專案也能找到適合的夥伴。

綜合以上所述，有兩位受訪者皆認為，推動青年在公民科技參與及議題的關心，並不需要成立「只有青年才能參與」的公民科技社群，只需營造一個「青年參與友善」的社群並提供輔助資源即可。之所以會提出青年專屬社群的解決方案，是因為希望能降低青年認知內參與的門檻。然而，在原本的公民科技社群中，提供提案輔導等協助，也能同樣降低參與門檻，讓青年擁有足以參與公民科技社群的能力與技術。加上有著前輩的引導，反而能夠提高參與動機，更不擔心在做專案過程中遇到問題。

### 四、小結

#### 1. U22 的公民科技參與現況
**(1) U22 投入公民科技專案的參與人數雖少但逐年上升**

U22 自主投入公民科技專案的人數逐年上升，且專案主題與議題多聚焦於教育/學習困境，如學習資源、學伴、遠距教學，部分則為影響青年的社會議題，如隨機殺人事件地點提醒地圖、夜間女性安全等。其中部分的學生群體會主動參加台日韓公民科技社群，在台日韓三方受訪學生的經驗中，U22 較為認識與參與的社群，皆為當地最大的公民科技社群，如台灣 g0v 零時政府社群、日本 Code for Japan 社群、韓國 Code for Korea 社群，與其他年齡層無太大差異。然而目前參與人數雖不多，但隨各國社群發展時間越長，且開始藉由舉辦競賽、培力課程，培育 U22 青年公民科技意識與能力，U22 社群參與者與投入公民科技專案的參與人數逐年提升，如 g0v 零時小學校專案、Code for Japan 「U22 公民科技挑戰賽（Civictech Challenge Cup U-22）」。

**(2) 學生公民科技專案易因學業壓力、經驗與資源有限而無法順利發展**

韓國與台灣的受訪大學生皆提及，平衡學業或外務會影響學生發展公民科技專案，台日韓教育目前仍以升學考試為主，因此學生較難在課業繁重的生活中，找到時間與心力發展專案。此外也容易因經驗與資源不足，無法順利解決專案困難，例如台灣學生因行銷宣傳經驗不足，導致觸及效果有限。然而當政府教育方針有所變化，將增加學生參與或發起公民科技專案的機會，例如台灣 108 課綱在高中階段增加自主學習課、探究與實作課程、多元選修課，因此學生可有更多時間發展專案，而 g0v 零時小學校也曾多次與高中老師合作，運用探究與實作或多元選修課，開設數位公民專案實作課，培育學生做專案。


#### 2. 參與公民科技的管道與建議

台日韓受訪學生針對如何支持 U22 青年參與公民科技，皆以增加資源、與學校合作、辦理相關競賽，以及與業界連結，增強社會對公民科技參與經驗的認可為方向，其中台灣學生更認為無需要建立專屬青年的公民科技社群，反而是降低現有公民科技社群的參與門檻，且有公民科技前輩的引導能增加參與動機並解決專案困境。

**(1) 當公民科技專案/社群參與經驗可提升入學與就業機會，將提升學生參與動力。**

A. 彙整學生運用公民科技參與經驗成就學業與職涯之故事，提供其他學生借鏡：

日本兩位受訪學生皆提及，學生參與公民科技的原因，主要為豐富學習歷程與履歷，增加就業機會。而台灣 g0v 零時小學校觀察，g0v 社群有不少高中生以參與或發起公民科技專案的經驗，作為申請大學時被審資料的重要經歷，並因此進入理想的校系。建議可以收集與彙整此些類型的經驗，提供他人參考路徑，並理解公民科技專案對生涯發展的具體影響力。

B. 增加社會對公民科技經驗之認同，並創造學生與業界之連結：

日本學生特別提及，社會對於公民科技專案經驗的高度認可，將讓學生更願意接觸公民科技。而另一方面，學生也應該要主動強調自身在專案中學習到的能力與態度，包含主動性、領導能力、創新、技術等，增強認可。此外，公民科技活動與企業合作也是提升認可度的辦法之一，目前 CfJ 在舉辦「U22 公民科技挑戰賽（Civictech Challenge Cup U-22）」皆會與企業合作，讓企業頒發獎項給各自認為的優秀團隊，而 2020 年多個獲獎團隊成員表示，專案經驗對於就業十分有幫助。

**(2) 無需創造專屬青年的公民科技社群，而是於原有的公民科技社群中降低參與門檻。**

A. 技術資源能具體協助學生開發公民科技專案：

除了公民科技社群，學生也需要技術支持資源/社群，因開發所需資源或部分數位工具皆需要費用，若能獲得免費或有折扣的機會，將更容易使得學生將專案從想像，透過開發落實。

B. 於現有教育體制中，促成與公民科技社群之合作：

韓國與台灣學生皆提及可與學校合作，包含教育單位引入公民科技相關課程與活動、邀請公民科技前輩共同建立導師制度、使用學生常使用的社群平台、提供學分認證／實習機會／獎學金。而在台灣，g0v 零時小學校已有與高中及大學合作課程的經驗，以及 g0v mentor 專案諮詢制度可參考。過往合作教師也回饋，連結現有的公民科技社群不僅有明確案例與模式可參考，也可減少教師對數位工具、公民科技概念與資源不熟的擔憂，增加教師合作開課的意願。

C. 辦理更符合公民科技相關的競賽：

韓國學生明確指出，韓國學生通常會參與各種競賽進而獲得專案資源，然而競賽常出現評審不一定理解公民科技專案。而目前台灣 g0v 零時小學校每年皆會辦「專案孵化競賽」、日本 CfJ 每年也會辦理「U22 公民科技挑戰賽（Civictech Challenge Cup U-22）」，兩者皆以公民科技為主題，並針對 U22 提供一定保障名額，以上兩個競賽皆成為台日學生參與公民科技的重要管道之一。綜合以上，建議可辦理以公民科技為主題的競賽。
