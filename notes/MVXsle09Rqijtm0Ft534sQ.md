fumilayo's imaginery is a digital media showcase built around a core mission:
turning abstract ideas into tangible art through digital illustration,creative graphics design,promotional assests and imaginative visual creation.
our name represents the combination of diverse ideas and creative vision coming toggether to build something completely new,every design starts with a single idea,and every idea has a potential to become art.

To bring this brand to life ,i built a multi-page web platform using semantically structured HTML and standard Git version control workflows.
 
****~~ BREAKDOWNS~~**** 

1. home page(ideas-index.html):establishes our brand and identity inside a semantic
Header and a site-wide navigaton bar NAV. a dedicated MAIN section introduces our visual mission using clear heading hierarchies h1 - h2 and structured blocks.

2. service page(service-index.html):
details our design offerings,rates,and packages ooption using a clean Table element.the content is organized with thead and tbody tags, utilizing colspan attributes to group tier levels efficiently.

3. about page(graphic-index.html)
highlights our creative portfolio.all visual assets utilize descriptive alt attributes for screen readers and accessibiltiy.the page also features embedded video/audio player with native media controls.

4. contact-inquiry page(contact-index.html)feauturesnan interactive Form, allowing potential clients to reach out. it incorporate explicit Label bindings,date /text inputs,customized Select, dropdown menus with discrete value parameters, selection options, and a textrea, for detailed project briefs backed by aside,containing external social links.

Throughout the development cycle,i followed professional software workflows using Git. instead of single final push, i loogged step-by-step progress using clear,descriptive commit messages for every page built. additionally,every document was validated against W3c standards to guarantee error-free,accessible code.
