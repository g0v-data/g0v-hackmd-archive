1. Jorge Luis Borges (博爾赫斯) — 無窮雙向連結的迷宮建造者
「我的想像力總是運作於圖書館與迷宮之間。」
* Logseq 實踐：[[雙向連結]] 與 Digital Garden
* 分析： 博爾赫斯在《小徑分岔的花園》與《巴別塔圖書館》中預言了超文本（Hypertext）。傳統筆記是線性的樹狀目錄，而博爾赫斯的思維是網狀且無限重疊的。
* Logseq 應用： Logseq 的雙向連結 [[概念]] 消除了一本書或一篇文章的「邊界」。在 Logseq 中，博爾赫斯不會將筆記歸類在某個資料夾，而是讓每一個標籤與引用成為一個分岔口，在圖譜（Graph View）中自然交織出一座無始無終的心智迷宮。

2. Edmund Husserl (胡塞爾) — 現象學日誌與意識流懸置
「回到事物本身 (Zurück zu den Sachen selbst)!」
* Logseq 實踐：Journal (每日日誌) 與無壓力的 Block capture
* 分析： 現象學強調捕捉體驗發生的當下，先不對其做範疇歸類（即「懸置 Epoché」）。傳統筆記讓人困在「這則筆記該放哪個資料夾」的分類焦慮中。
* Logseq 應用： Logseq 預設開啟就是當天的 Journal。胡塞爾可以在 Journal 頁面中順應意識流，隨手記錄下任何閃過腦海的現象與感悟，不需事先規劃分類。透過大綱的縮排與結構，將粗糙的意識體驗逐步結構化，還原出思想的本質。

3. Douglas Hofstadter (侯世達) — 遞迴塊結構與自指奇異環
「『我』就是一個奇異環（Strange Loop）。」
* Logseq 實踐：((Block Reference)) / 縮排遞迴與模組化
* 分析： 侯世達在《哥德爾、埃舍爾、巴赫 (GEB)》中探索了系統如何透過簡單規則的重複與自指，湧現出複雜的高階智慧。
* Logseq 應用： Logseq 的最小單位是 Block（塊），而非頁面。Block 可以無限嵌套，也可以被引用（Block Ref）或嵌入（Block Embed）到另一個完全不同的脈絡中。這正是侯世達所痴迷的「分形與遞迴」：一個簡單的句塊，在不同頁面間相互引用，形成了邏輯上的自指迴圈，讓知識庫產生階層湧現（Emergence）。

4. Alan Kay (艾倫·凱) — 將筆記視為動態物件的軟體環境
「預測未來的最好方式，就是把它發明出來。」
* Logseq 實踐：Block Properties / Query 查詢語法與外掛生態
* 分析： 作為個人電腦與物件導向程式設計（OOP）的先驅，Alan Kay 認為電腦不該只是「電子化的紙張」，而應是「可互動的動態介面」。
* Logseq 應用： 在 Logseq 中，每個 Block 都可以賦予屬性（如 type:: book, status:: reading），透過 {{query ...}} 或 Datalog 進行動態資料檢索。Logseq 不只是個文字編輯器，而是一個小型資料庫，符合 Alan Kay 對「動態卡片媒體」的終極想像。

5. Audrey Tang (唐鳳) — 開放在地架構與透明脈絡
「網路不只改變了資訊傳播，更改變了我們共同思考的方式。」
* Logseq 實踐：Local-first (在地純文字) / Git 整合 / 綠色軟體哲學
* 分析： 唐鳳長期倡導開放原始碼、數位公地（Digital Commons）與資料自主權。
* Logseq 應用： Logseq 的所有資料均以標準 Markdown 或 Org-mode 純文字檔儲存在使用者本機，不依賴封閉的雲端伺服器。這符合唐鳳對數位基礎建設「資安、透明、自主、開放」的要求。使用者可以用 Git 管理版本演進，甚至將個人圖譜輕鬆導出為網頁，實現真正的知識民主化與個人資料主權。

總結： Logseq 的設計哲學，正是用 胡塞爾 的現象學日誌捕捉當下，用 博爾赫斯 的網狀連結延伸脈絡，用 侯世達 的遞迴塊架構湧現思想，在 Alan Kay 的動態介面上運行，並以 唐鳳 所倡導的開放標準與資料主權妥善保存。
